# Starlink Business 紹介LP（自主制作ポートフォリオ）

KDDIの法人向け衛星通信サービス「Starlink Business」を題材に自主制作した、紹介LPとお問い合わせページです。KDDI公式の発表資料をもとに、数字と導入事例の出典を確認しながら制作しました。

## 公開中のサイト
https://starlink-business-portfolio.urstoryvideo.chatgpt.site/

## 想定読者
建設・インフラ現場の通信環境を担当する、建設会社本社の担当者

## 工夫した点
- 光回線が使える場所では光が有利なことを先に認め、Starlinkが埋める「エリア・時間・冗長性」の3つの穴に絞って訴求
- 導入実績はStarlink Businessの公式事例に統一（大林組／日本取引所グループ／郵船クルーズ）
- 料金は公式サイトと同様に非公開とし、見積もり・相談への導線で設計
